# 《海狮模拟器》V1.0 设计规格

## 产品与角色

《海狮模拟器》是一个无需登录、无后端、可部署到 GitHub Pages 的 2D 侧视图网页游戏。用户在本任务中是生产者；主要目标用户是儿童、普通玩家及希望直观看懂动物学习机制的观察者。

首版需要同时完成两个用户任务：

1. 玩家能够直接控制“小浪”完成游泳、潜水、换气、捕猎、上岸、休息和物体互动。
2. 观察者能够布置环境、运行实验，并从效用分数、行为日志、记忆和学习价值中理解海狮为何改变选择。

成功信号是玩家能在 3 分钟内观察到至少一次“尝试—结果—记忆—后续偏好变化”，并能在不阅读说明书的情况下切换海狮/研究员模式。V1.0 的体验目标不是科研有效性，而是机制真实、规则透明、行为可观察的游戏化模拟。

## 视觉与交互方向

视觉概念为“温暖的自然观察站”。画面使用程序化矢量纹理与几何组合：青蓝海湾、暖灰礁石、带浅金高光的水下光束、橙色研究装置。海狮保持流线形动物姿态，通过头部方向、鳍、尾鳍、游速、身体角度和气泡表达动作，不站立、不说话、不使用复杂人类工具。

画面采用 1600×900 逻辑尺寸和 Phaser `Scale.FIT`，保证电脑、iPad 与手机横屏共享同一空间坐标。HUD 固定在安全区；默认仅展示饥饿、精力、氧气。高级状态、研究工具、记忆和智能观察分别使用可展开面板。触控使用左侧虚拟摇杆和右侧 56px 以上动作按钮。重要信息同时用图标、文字与形态表达，不仅依靠颜色。

环境动效都有语义：水面波动表示边界，光束表示水深，气泡表示呼吸路径，水草摆动表示水流，水花表示入水，鱼群转向表示受惊。`prefers-reduced-motion` 下减少循环幅度和粒子数量，但不移除状态反馈。

## 运行架构

项目采用 Vite、TypeScript、Phaser 3、CSS、Web Audio API、localStorage 和 Vitest。没有远程字体、CDN、图片依赖、服务器或商业素材。

架构分为四层：

- `game/types` 与 `game/config` 定义稳定数据合同和可调参数。
- `game/systems` 是无 Phaser 依赖的确定性模拟内核，负责生理、感知、效用决策、记忆、强化学习、实验、存档和音效状态。
- `game/entities` 与 `game/behaviors` 把内核决策映射为 Phaser 物理运动、动画和交互。
- `game/scenes` 与 `game/ui` 负责场景编排、研究工具、生日阶段、输入和呈现。

场景共享同一个 `SimulationContext`。自由海湾、实验室和生日模式只改变初始物体、实验合同和流程目标；它们都调用同一个 `UtilityAISystem`、`MemorySystem`、`LearningSystem` 与 `InteractionSystem`。

## 世界与实体

海湾世界宽 1600、高 900。水面位于 y=215；海底随 x 缓慢加深。左侧为浅滩和可爬上的礁石平台，中央为鱼群区，右侧为深水和实验平台。海狮使用 Arcade Physics，但核心状态和决策以逻辑时间推进。

小鱼运行简化群游：对邻鱼的聚合/对齐、随机转向、边界和礁石避让，以及海狮接近时的逃逸。捕食碰撞后由距离、相对速度、精力、鱼的逃逸状态和接近方向计算成功概率；随机源可注入，自动测试使用种子随机数。

交互物体统一实现 `InteractiveObject` 合同，包含实例 ID、类型、形状特征、位置、新颖度、可推动/可拍打/可打开属性、奖励规则和危险强度。学习键使用“对象类型 + 特征 + 动作”，位置仅进入情境修正，因此位置交换后仍能迁移形状经验，又不会完全忽略地点记忆。

## 生理与动作

状态范围统一夹在 0–100，并使用每秒小增量平滑变化：

- 水下消耗氧气，水面或岸上恢复；氧气低于 18 时强制呼吸门控。
- 饥饿随时间增加，成功进食降低。
- 游泳、追逐与加速消耗精力，水面漂浮和岸上休息恢复。
- 体温受水深与休息位置缓慢影响。
- 陌生物体和突发声音提高恐惧；安全探索、距离增加和休息降低恐惧。
- 成功探索提高熟悉度并让好奇逐步回落；新刺激提高好奇。
- 来自研究装置的重复正面结果缓慢提高信任。

动作由行为对象实现，具有 `minimumDuration`、`cooldown`、中断条件与完成条件。海狮模式下有效玩家输入暂时接管移动，松开后自动行为恢复；自动开关可完全关闭自主选择，但生理保护仍会提示低氧。

## Utility AI

AI 每 800ms 重算候选行为，不逐帧改主意。通用评分为：生理需求 + 环境刺激 + 记忆 + 性格 + 预计奖励 − 风险 − 消耗 + 有界噪声。

候选行为包括呼吸、找鱼、追鱼、休息、上岸、下水、探索、推动、拍打、逃离、接近熟悉物、叫声、巡游和重复成功动作。每个候选保存总分和命名因素，供智能观察面板显示。

硬门控如下：氧气极低时 `surface` 以不可被普通奖励超越的分数胜出；恐惧极高且存在危险源时 `escape` 优先；精力极低时追逐和加速受到强惩罚；饥饿越高越愿意承担食物风险；好奇和探索性格越高越愿意接近陌生物。

## 记忆与学习

记忆条目记录对象、类型、特征、位置、动作、成功、奖励、风险、强度、创建时间和最后使用时间。相同对象/动作/结果的重复经验合并增强；时间衰减后清理弱项；最多保留 50 条，优先保留强度、近期性与风险较高的记忆。

学习值使用可解释增量更新：`new = old + learningRate × (reward - old)`。成功的奖励为正，失败和无结果为小负值，危险为更大负值。行为选择使用学习值、记忆位置相似度和性格探索率；探索概率随尝试次数缓慢下降但保留底线，规则改变后负反馈会逐步覆盖旧价值，而非一次清零。

## 研究员与实验

研究员模式冻结直接控制，不冻结海狮。工具栏可以放置鱼、三种形状按钮、浮球、箱子、食物盒、圆环、障碍和声音装置；桌面鼠标与触控均可拖动对象。研究员只能改变环境或实验规则，不能编辑能力值。

三个实验由 `ExperimentSystem` 记录尝试、成功、偏好、最近行为、价值变化和完成条件：

- 位置记忆：食物在三个箱子之一，成功后交换实例位置，比较位置记忆与箱体特征的影响。
- 形状学习：圆形按钮奖励鱼，其他按钮无奖励，位置交换不改变正确特征。
- 规则改变：保留旧学习值，把奖励从圆形切到三角形，记录旧规则错误与后续重新学习。

结果由真实交互事件驱动；实验系统只统计和改变奖励映射，不直接指定海狮下一动作。

## 生日体验

生日配置集中在 `src/game/config/birthday.ts`，含显示开关、称呼、日期、署名和祝福。

生日流程目标时长 150–210 秒：认识海狮 → 形状训练 → 规则改变 → 组合生日箱。阶段控制器只决定可用装置、说明和完成判据。海狮仍由通用 AI 选择接近、拍打和推动；超时辅助仅逐步提高探索概率、降低非目标干扰物效用，绝不直接触发成功。

生日箱需要先接近、再推动到可交互区、再拍打当前正确按钮。完成后才播放水花、气泡、顶牌和祝福动画。

## 存档、错误与音效

存档版本固定为 `1.0`，保存名字、性格、生理状态、学习值、重要记忆、设置、生日完成与实验成绩。读取时验证形状并逐字段采用安全默认值；无法解析、版本不支持或数值非法时恢复默认，不阻断启动。重置学习只清记忆/价值/实验记录，删除全部存档需要明确二次确认。

音效用 Web Audio API 合成水花、气泡、叫声、吞食、按钮、箱子和庆祝声。首次用户手势后创建/恢复音频上下文；静音和音量设置持久化。

## 测试与验收

Vitest 覆盖生理、Utility AI、记忆、学习、存档、实验和 10 分钟无界面模拟。浏览器验收覆盖桌面 1440×900、手机横屏约 844×390、键盘主路径、触控目标、面板展开、模式切换、控制台、资源加载、横向溢出和减少动态效果。生产构建必须使用相对资源路径，GitHub Actions 把 `dist/` 部署到 Pages。

V1.0 对“真实”的声明边界是：行为规则参考常识级动物生理与学习机制，但没有经过科研数据校准，不用于动物训练、安全或科研结论。
