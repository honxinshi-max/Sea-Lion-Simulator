# V1.0 重要设计决定

## 产品角色

本项目按“生产者”任务处理。目标用户是儿童与普通玩家、亲子共同体验者，以及希望观察简化动物行为机制的玩家。默认界面优先解释“现在在做什么”，高级数值放入详细状态和智能观察面板；反馈闭环由行为日志、实验统计、记忆列表和学习值变化组成。

## 模拟核心与渲染分离

`SimulationSystem` 不依赖 Phaser，可在 Vitest 中以固定 100ms 步长运行。Phaser 场景只负责输入、程序化绘制、声音和呈现。这使 10 分钟稳定性、存档恢复、生日流程和规则反转可以在浏览器外快速验证。

## Utility AI 而非固定剧本

候选行为由生理、感知、记忆、性格、学习价值、风险、成本和轻微噪声共同评分。行为通过锁定时间避免逐帧摇摆；缺氧和极端恐惧可中断普通决定。探索率通过 epsilon 探索实际进入决策，不是只显示在面板上的装饰值。

## 记忆与强化学习分工

- 记忆保存对象身份、类型、特征、位置、动作、成败、奖赏、风险、强度和时间，并随时间衰减。
- 学习值按 `物体类型 | 特征 | 动作` 更新，使用 `新值 = 旧值 + 学习率 × (实际奖励 - 旧值)`。
- 因此交换位置仍可迁移形状经验，而位置记忆又会造成短期旧位置干扰。

## 生日模式辅助边界

生日流程使用相同的生理、感知、Utility AI、记忆、学习和互动系统。辅助机制在阶段停留过久后才逐渐出现，只会：

1. 提高探索概率；
2. 为当前应尝试的候选动作增加可解释效用；
3. 周期性把目标移回可感知、可到达范围。

它不会伪造互动事件、直接修改学习值或跳过成功率判断。阶段转换只接受实际生成的行为事件，并使用尝试索引隔离不同阶段，避免旧事件被重复计数。

## 无版权素材策略

所有动物、鱼、岩石、水草、按钮、箱子、气泡、水花和标牌均由 Phaser Graphics、文字与几何图形即时绘制。声音由 Web Audio API 振荡器和噪声缓冲合成。项目没有外部素材下载依赖。

## 部署策略

Vite 使用 `base: './'` 生成相对资源路径，适配 GitHub Pages 仓库子路径。部署工作流先运行测试和生产构建，再上传 `dist/`；部署本身留给未来仓库完成后执行。
