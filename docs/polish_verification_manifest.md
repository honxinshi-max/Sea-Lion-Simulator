# Polish Verification Manifest

## 自动化

- TypeScript 严格类型检查：`npm run typecheck`
- Vitest 全量测试：`npm test`
- 生产构建：`npm run build`
- 10 分钟纯模拟长跑：包含在 `tests/simulation.test.ts`
- 生日多随机种子长跑：包含在 `tests/birthday-integration.test.ts`

## 浏览器关键路径

- 桌面主菜单 → 自由海湾 → 键盘移动 → 研究员模式 → 形状学习实验 → 智能观察。
- 生日入口 → 介绍页 → 训练阶段。
- 手机横屏 844×390：主菜单、海狮触控控制、研究工具双页、实验启动、返回海狮模式。
- 浏览器控制台：检查 error / warning。
- 生产预览：验证 `dist/` 中相对资源可加载。

## 响应式与可访问性

- 目标视口：1440×900、1024×768、844×390。
- 竖屏窄设备显示旋转提示。
- Canvas 可聚焦并提供应用角色和键盘说明。
- 核心操作同时提供键盘与触控；菜单支持方向键、回车、空格和数字快捷键。
- 状态条同时显示文字、数值和颜色，不以颜色作为唯一反馈。
- `prefers-reduced-motion` 和游戏内“减少动态”设置会限制循环环境动画。
