# 视觉与交互 Taste Audit

评审对象：海狮模拟器 V1.0。目标受众：儿童与普通玩家、亲子共同体验者、动物行为观察兴趣用户。

## 评分

| 维度 | 分数 | 说明 |
| --- | ---: | --- |
| 视觉层级 | 18/20 | 海湾、角色、基础 HUD 与研究面板层级清楚；移动端保留核心场景面积。 |
| 排版 | 13/15 | 采用系统中文字体并控制行宽；手机横屏上的高级日志字号仍偏小。 |
| 间距与构图 | 13/15 | 桌面布局呼吸感充分；研究员面板在手机上改为双页，避免工具拥挤。 |
| 色彩 | 14/15 | 暖沙色强调与蓝绿色海湾形成稳定对比，状态不只依赖颜色。 |
| 表面与细节 | 12/15 | 程序化轮廓、分层水域和交互反馈统一；V1.0 不追求复杂材质。 |
| 动效 | 9/10 | 水面、水草、气泡、鱼群、水花和动作状态可辨识；支持减少动态。 |
| 一致性 | 9/10 | 菜单、HUD、弹窗、研究面板共用按钮与面板语言。 |

总分：88/100。

## 已完成的视觉修复

- 修复捕猎状态逐帧乘法缩放导致海狮不断变大的问题，改为纯函数计算目标比例。
- 手机横屏主菜单与主要触控按钮使用约 44px 的实际命中高度。
- 研究工具台在手机横屏中拆分为“放置物体 / 实验与记录”两页，并使用统一面板命中层。
- 研究员模式隐藏海狮控制摇杆，避免覆盖实验面板；面板提供“返回海狮”。
- 系统或游戏设置启用减少动态时，停止循环水面、水草、气泡与呼吸摆动，水花数量也会降低。

## 保留限制

- 高级行为日志在 844×390 视口中以信息密度优先，字号小于桌面版本。
- 程序化海狮采用轮廓姿态而不是骨骼动画，动作表达依赖转向、速度、形变、标签和行为文字共同完成。
- 画面不使用外部插画，品牌辨识主要来自颜色、海湾构图和小浪轮廓。
