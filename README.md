# 海狮模拟器 V1.0

🎮 **[立即游玩海狮模拟器](https://honxinshi-max.github.io/Sea-Lion-Simulator/)**

> GitHub Pages 路径区分大小写，请保留 `Sea-Lion-Simulator` 的大小写与末尾 `/`。

《海狮模拟器》（Sea Lion Simulator）是一款运行在浏览器中的 2D 侧视动物生活与认知学习游戏。玩家可以直接控制海狮“小浪”在海湾中游泳、潜水、呼吸、捕猎、上岸和休息，也可以切换到研究员模式，布置物体与实验，观察它如何在生理需求、环境刺激、性格、记忆和结果经验之间做选择。

这不是科研软件，也没有用单一“智商值”包装随机移动。游戏采用可解释 Utility AI、有限容量记忆和渐进式行为价值更新；每次成功或失败只改变后续选择概率，不会让小浪瞬间永久学会。

## 核心功能

- 自由海湾：可直接控制，也可开启自主行动持续观察。
- 生理状态：饥饿、精力、氧气、体温、恐惧、好奇和信任均限制在 0–100，并随活动平滑变化。
- 自主行为：呼吸、寻鱼、捕猎、休息、上岸、下水、探索、推动、拍打、逃避、叫声和巡游等行为通过效用评分选择，并带最短持续时间与紧急中断保护。
- 记忆与学习：最多保留 50 条重要记忆；记忆会衰减，重复结果会强化相应经验；学习值按物体类型、特征和动作保存。
- 捕食：鱼群会移动、逃避、重生；捕食成功率取决于距离、速度、精力、逃跑状态和接近方向。
- 研究员模式：放置或拖动鱼、浮球、三种按钮、箱子、食物盒、圆环、障碍和声音装置。
- 三个实验：位置记忆、形状学习、规则改变。实验统计来自真实互动事件，不写死结果。
- 智能观察：显示行为效用、主要影响因素、最近记忆、学习价值和探索概率。
- 生日实验：约 2 分 30 秒至 3 分 30 秒的学习体验，包含错误、成功、规则反转和组合机关；超时辅助只渐进提高探索倾向。
- 本地存档：状态、性格、记忆、学习、设置、生日完成记录和实验成绩保存在 `localStorage`，结构版本为 `1.0`。
- 响应式输入：电脑键盘、iPad 和手机横屏触控；竖屏会提示旋转设备。
- 程序化美术与声音：所有画面由 Phaser Graphics/文字/几何图形生成，音效由 Web Audio API 合成。

## 安装与启动

需要 Node.js 22 或兼容的当前 LTS 版本。

```bash
npm install
npm run dev
```

开发服务器默认监听 `http://localhost:5173`。项目无需后端、账号或外部素材服务。

## 测试与构建

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

生产文件生成到 `dist/`。Vite 使用相对资源基址，因此既可部署在仓库根路径，也可部署在 GitHub Pages 的仓库子路径。

测试覆盖生理状态、Utility AI、行为持续时间、记忆、学习、互动、存档损坏恢复、三个实验、输入映射、场景契约、10 分钟模拟稳定性以及多随机种子的完整生日流程。

## GitHub Pages 部署

仓库准备好后：

1. 将本目录作为 Git 仓库根目录提交并推送到 GitHub，默认分支使用 `main`。
2. 在 GitHub 仓库进入 **Settings → Pages**。
3. 将 **Build and deployment / Source** 设为 **GitHub Actions**。
4. 推送到 `main`，或在 **Actions → Deploy GitHub Pages** 手动运行。
5. 工作流会执行 `npm ci`、`npm test`、`npm run build`，随后发布 `dist/`。

部署工作流位于 `.github/workflows/deploy.yml`。合并源码到 `main` 后，按上面的仓库设置启用 GitHub Actions 即可发布。

## 键盘操作

| 按键 | 操作 |
| --- | --- |
| `W` / `↑` | 上浮 |
| `S` / `↓` | 下潜 |
| `A` / `←` | 向左游 |
| `D` / `→` | 向右游；研究员模式中打开智能观察 |
| `Shift` | 短时加速（极低精力时受保护） |
| `Space` | 互动、捕食或拍打当前目标 |
| `E` | 发出叫声 |
| `R` | 休息 |
| `Tab` | 切换海狮 / 研究员模式 |
| `P` | 暂停 |
| `M` | 静音 |
| `I` | 智能观察 |
| `1` / `2` / `3` | 研究员模式中启动位置 / 形状 / 规则改变实验 |

主菜单支持方向键选择、回车或空格确认；数字 `1`–`4` 可快速进入自由海湾、继续游戏、生日实验和实验室。

## 触控操作

- 左下虚拟摇杆：游动、上浮和下潜。
- 右下按钮：互动、加速、叫声、休息和切换模式。
- 研究员模式：工具台分为“放置物体”和“实验与记录”两页；按钮采用适合手机横屏的放大命中区域。
- 研究物体可拖动；“返回海狮”回到直接控制。
- 手机竖屏时请旋转到横屏。

## 修改生日文字

编辑 [`src/game/config/birthday.ts`](src/game/config/birthday.ts)：

```ts
export const BIRTHDAY_CONFIG = {
  enabled: true,
  addressee: '爸爸',
  date: '2026-08-24',
  creator: '你的署名',
  message: '你的祝福文字',
};
```

将 `enabled` 改为 `false` 会从主菜单隐藏生日入口。修改后重新运行测试和构建。

## 修改海狮性格

玩家可以在“设置”中选择好奇型、谨慎型或活跃型。三种性格会实际改变好奇、胆量、耐心、学习率、探索率、社交和活跃效用。

开发者可编辑 [`src/game/config/personality.ts`](src/game/config/personality.ts)，各参数范围应保持在 0–1。数值平衡位于 [`src/game/config/balance.ts`](src/game/config/balance.ts)。

## 存档、继续与重置

- 游戏中点击“保存”，或返回菜单 / 页面隐藏时，会保存当前状态。
- 主菜单“继续游戏”读取最近存档。
- “设置 → 重置学习”只清除记忆、学习值和实验成绩，保留生理状态与设置。
- “设置 → 删除全部存档”恢复全部默认值。
- 两个清除操作都有二次确认。
- 如果存档 JSON 损坏、字段异常或版本不兼容，游戏会安全回退到默认存档。

浏览器开发者工具中也可手动删除键 `sea-lion-simulator-save`，但正常游玩无需这样做。

## 设计说明

- 紧急需求优先：极低氧气强制上浮；极高恐惧优先逃离；极低精力压低追逐和冲刺。
- 决策不是逐帧变化：行为有最短持续时间，只有紧急保护能越过普通行为锁定。
- 学习不等于记位置：行为价值按物体类型、特征和动作保存；位置保存在会衰减的记忆中。
- 规则改变保留旧经验干扰：旧价值先产生错误，再通过新结果逐步修正。
- 生日辅助不写成功事件：它只周期性将目标带入可感知范围，并提高某个候选动作的探索效用与被选择概率；互动仍由同一套 Utility AI 和成功判定完成。

## 已知限制

- V1.0 是真实基础上的游戏化模型，并未用真实个体数据做科研标定，不应用于动物福利或行为研究结论。
- 首版只有一只海狮、一种鱼群和小型单场景生态；碰撞与岸上运动采用简化区域模型。
- 程序化动画以可读性为先，没有骨骼动画、复杂水体物理或写实声学。
- Phaser 本身使首包体积较大；游戏不依赖网络资源，但低性能设备首次解析可能稍慢。
- 存档仅位于当前浏览器和当前站点域名，清理浏览器数据会删除存档。

## 后续版本方向

- 增加更多个体差异、长期习惯与睡眠节律。
- 加入更丰富的鱼群、潮汐和可破坏 / 可组合环境物体。
- 提供实验数据导出和可复现实验种子，但继续保持“游戏而非科研软件”的边界。
- 改进屏幕阅读器可访问性和可重映射操作。
- 在不改变学习机制的前提下扩展程序化动画和环境声景。
